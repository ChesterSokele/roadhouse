Step-by-step

1

Create a Firebase Project

Go to console.firebase.google.com and sign in with your Google account.

  • Click Add project
  • Name it roadhouse-deli-grill (or anything you like)
  • Disable Google Analytics (not needed) → click Create project
  • Wait ~30 seconds for it to provision, then click Continue
💡The free Spark plan is more than enough — you get 1 GB storage, 50,000 Firestore reads/day, and 10 GB hosting.
2

Register a Web App & Get Your Config

In your new project's dashboard:

  • Click the </> (Web) icon under "Get started by adding Firebase to your app"
  • Enter app nickname: Roadhouse Website
  • Skip Firebase Hosting for now → click Register app
  • You'll see a code block — copy the firebaseConfig object
💡It looks like this — yours will have real values instead of placeholders:
const firebaseConfig = {
  apiKey:            "AIzaSy...",
  authDomain:        "roadhouse-deli.firebaseapp.com",
  projectId:         "roadhouse-deli",
  storageBucket:     "roadhouse-deli.appspot.com",
  messagingSenderId: "123456789",
  appId:             "1:123..."
};
⚠️Do not share your apiKey publicly. It's okay in front-end code only because we'll lock it down with Firestore Rules in Step 5.
3

Paste the Config into Your Files

Open these two files in any text editor and replace YOUR_API_KEY, YOUR_PROJECT_ID etc. with your real values:

📄admin.htmlFind const firebaseConfig = { near the bottom
📄index.htmlFind const firebaseConfig = { inside the Firebase script block at the bottom
💡Use Ctrl+F (or Cmd+F) in your text editor to search for YOUR_API_KEY — it'll jump straight to the right place.
4

Enable Firebase Authentication

This is your login system for the admin panel.

  • In Firebase Console → left sidebar → Build → Authentication
  • Click Get started
  • Under "Sign-in method" click Email/Password → Enable → Save
  • Go to the Users tab → click Add user
  • Enter your email and choose a password → click Add user
✅That email + password is what you'll use to log into admin.html
5

Create the Firestore Database

  • Firebase Console → Build → Firestore Database
  • Click Create database
  • Choose Start in production mode → Next
  • Select your region (e.g. europe-west1) → Enable
  • Wait ~30 seconds for it to provision

Set up Security Rules. Click the Rules tab and paste this:

// Firestore Security Rules for Roadhouse
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Everyone can read — no sensitive data here
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null; // only logged-in admin can write
    }

    // Anyone can submit a review (create only, not edit/delete)
    match /reviews/{id} {
      allow create: if true;
    }
  }
}

Click Publish.

💡These rules let the public read active content and submit reviews, but only you (logged in) can create/edit/delete anything.
6

Enable Firebase Storage (for Images)

  • Firebase Console → Build → Storage
  • Click Get started → Start in production mode → Next → Done
  • Click the Rules tab and paste:
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

Click Publish.

7

Open the Admin Panel

Open admin.html in your browser (or deploy — see Step 8). Log in with the email and password you created in Step 4.

  • Add your first Event (date, title, description, image)
  • Add Specials (name, price, badge like "Mon–Fri")
  • Update each day's Meal of the Day
  • Incoming Reviews from the website appear here — approve to show them
  • Add a Notice to show a banner on the homepage (e.g. "Closed on public holidays")
✅Any change you save appears on the website instantly — no page reload needed for visitors.
8

Optional: Deploy to Firebase Hosting (Free)

This gives you a free public URL like roadhouse-deli.web.app. You'll need Node.js installed.

npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy

Or just host your files with any regular web host (Netlify, cPanel, etc.) — Firebase Hosting is completely optional since we're only using Firestore + Auth + Storage.

Your setup checklist

  • Firebase project created
  • Web app registered & config copied
  • Config pasted into admin.html and index.html
  • Email/Password Auth enabled & admin user created
  • Firestore created with Security Rules published
  • Storage enabled with Storage Rules published
  • Logged into admin.html successfully
  • First event or special added — visible on website ✅

Firestore data structure (for reference)

events/
  {id}: title, description, date, time, tag, imageURL, imagePath, active

specials/
  {id}: name, description, price, badge, imageURL, imagePath, active

mealOfDay/
  "0" (Sun): name, desc, price, imageURL
  "1" (Mon): ...  "2" (Tue): ...  "3" (Wed): ...
  "4" (Thu): ...  "5" (Fri): ...  "6" (Sat): ...

reviews/
  {id}: name, text, rating, approved, pinned, createdAt

notices/
  {id}: text, active, createdAt
